# NBI Escape Game

A fast-paced running game where you must escape from the NBI (National Bureau of Investigation)!

## Features

- **Dynamic Running Mechanics**: Smooth character movement with jump and duck mechanics
- **Obstacle Avoidance**: Dodge various obstacles and NBI agents
- **Power-ups**: Collect items to boost your speed and invincibility
- **Scoring System**: Earn points based on distance and obstacles avoided
- **Progressive Difficulty**: Game gets harder as you progress
- **Responsive Controls**: Keyboard controls for desktop play

## How to Play

1. Open `index.html` in your web browser
2. Use **Arrow Up** or **Space** to jump over obstacles
3. Use **Arrow Down** to duck under obstacles
4. Avoid NBI agents and obstacles
5. Collect power-ups for temporary benefits
6. Try to beat your high score!

## Game Mechanics

- **Jump**: Press UP ARROW or SPACE to jump
- **Duck**: Press DOWN ARROW to duck
- **Speed**: Character automatically moves forward
- **Obstacles**: Various obstacles appear at different heights
- **Power-ups**: Speed boost and invincibility items
- **Game Over**: Collision with obstacle ends the game

## Files

- `index.html` - Main game HTML file with game canvas
- `css/style.css` - Game styling and UI
- `js/game.js` - Main game logic and engine
- `js/player.js` - Player character class
- `js/obstacle.js` - Obstacle management
- `js/powerup.js` - Power-up system

## Technical Stack

- HTML5 Canvas for graphics
- Vanilla JavaScript for game logic
- CSS3 for styling

## Installation

1. Clone the repository
2. Navigate to the game directory
3. Open `index.html` in your browser
4. Start playing!
